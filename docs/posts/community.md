## projects

| Project                                                                     | Category           | Description                                                                                                                                  |
| --------------------------------------------------------------------------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| [zsm](https://github.com/mdsakalu/zmx-session-manager)                      | Session manager    | TUI session manager to list, preview, filter, and kill sessions from an interactive terminal UI.                                             |
| [zmx-picker](https://github.com/EarthmanMuons/zmx-picker)                   | Session picker     | `fzf`-based session picker and project launcher. Jump to a running session or start one inside any `git`/`jj` repo.                          |
| [emacs-term-sessions](https://github.com/ArthurHeymans/emacs-term-sessions) | Editor integration | Persistent terminal sessions in Emacs, both local and remote.                                                                                |
| [pi-zmx](https://github.com/deevus/pi-zmx)                                  | AI / Agent         | [pi](https://pi.dev) extension for `zmx`.                                                                                                    |
| [rootshell](https://github.com/kitknox/rootshell)                           | Terminal client    | Metal-accelerated terminal for iPhone, iPad, Vision Pro, and Mac. Lists active `zmx` sessions with live previews and auto-attach on connect. |
| [zmosh](https://github.com/mmonad/zmosh)                                    | Fork / Transport   | Fork of `zmx` that adds encrypted UDP auto-reconnect for remote sessions (like `mosh`).                                                      |
